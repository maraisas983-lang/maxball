# MAXBALL para Android

[Baixar MAXBALL 1.0.20](MAXBALL-1.0.20.apk?raw=true)

A versão 1.0.20 corrige o APK enviado em modo local: agora abre https://maxball.onrender.com para cadastro, login e online. A confirmação por e-mail aparece na tela de entrada. Veja [Cadastro no APK](../docs/CADASTRO_APK_1_0_20.md). O sistema online e a física permanecem como na 1.0.19.

APK de teste, assinado com certificado de depuração, para Android 8.0 ou superior. Transfira para o celular, abra o arquivo e autorize a instalação pelo aplicativo usado. Quem instalou a versão anterior pode escolher **Atualizar**, preservando os dados.

A versão 1.0.13 aumenta o tamanho da bola em mais 6%, preservando o peso, o rolamento e as velocidades aprovados. O chat fica no rodapé, e os emotes adquiridos têm um botão próprio, separado das mensagens. Veja [Bola e chat](../docs/BOLA_CHAT_1_0_13.md).

Este APK já está configurado para o servidor HTTPS do MAXBALL; contas e partidas online precisam de internet. Os arquivos locais continuam usando a origem HTTPS interna introduzida na 1.0.1. O APK foi compilado e verificado; ainda falta teste em aparelho físico.
