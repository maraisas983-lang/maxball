# MAXBALL para Android

[Baixar MAXBALL 1.0.5](MAXBALL-1.0.5.apk?raw=true)

APK de teste, assinado com certificado de depuração, para Android 8.0 ou superior. Transfira para o celular, abra o arquivo e autorize a instalação pelo aplicativo usado. Quem instalou a versão anterior pode escolher **Atualizar**, preservando os dados.

Esta edição oferece os modos locais, entrada em campo, música e efeitos. A versão 1.0.5 substitui os contatos artificiais por impulsos com massa e reação nos dois corpos, estabiliza as divididas e fortalece o passe para abrir distância durante a corrida. Cada pressionamento humano gera uma única ação. Veja a [calibração, estrutura física e testes](../docs/FISICA_1_0_5.md). Permanecem a cor da grama, o acabamento 2.5D, o lobby horizontal, os tamanhos independentes dos controles e a correção de áudio da rede.

Online, contas e pagamentos exigem um servidor HTTPS publicado e outra compilação configurada com sua origem. Os arquivos locais continuam usando a origem HTTPS interna introduzida na 1.0.1. O APK foi compilado e verificado; ainda falta teste em aparelho físico.
