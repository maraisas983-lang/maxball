# MAXBALL para Android

[Baixar MAXBALL 1.0.1](MAXBALL-1.0.1.apk?raw=true)

APK de teste, assinado com certificado de depuração, para Android 8.0 ou superior. Transfira para o celular, abra o arquivo e autorize a instalação pelo aplicativo usado. Quem instalou a versão anterior pode escolher **Atualizar**, preservando os dados.

Esta edição oferece os modos locais, entrada em campo, música e efeitos. Online, contas e pagamentos exigem um servidor HTTPS publicado e outra compilação configurada com sua origem. A versão 1.0.1 troca o carregamento por `file://` por uma origem HTTPS interna, atendida exclusivamente pelos arquivos do APK, após relato de página indisponível. O funcionamento dessa atualização em aparelho físico ainda precisa ser confirmado.
